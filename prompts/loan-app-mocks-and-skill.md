# Использованный промпт: моки Playwright и AI-скилл

Завершить работу с Loan App, изучив существующие тесты, Page Objects, хелперы,
конфигурацию Playwright и историю Git.

Реализовать отдельные тесты с Playwright-моками для трёх ответов на реальный
запрос приложения:

1. Статус 500 и пустое тело ответа.
2. Статус 200 и пустое тело ответа.
3. Статус 200 и тело с неверным именем ключа вместо поля из контракта.

Для каждого сценария проверить состояние интерфейса. URL, метод запроса,
формат тела, локаторы и ожидаемое поведение брать только из контракта,
существующего кода или фактического DOM/Network. Не придумывать локаторы и
ожидания. Регистрировать `page.route(...)` и, если требуется,
`page.waitForResponse(...)` до действия, запускающего запрос. Если контракт не
задаёт UI для ошибочного ответа, описать фактическое поведение и вынести вопрос
преподавателю.

Создать или доработать `SKILL.md` для добавления тестов Loan App, включая
изучение тестов, Page Objects и конфигурации, порядок подготовки сетевого мока,
проверку UI и запуск нового и полного набора тестов. Применить скилл минимум к
одному сценарию, просмотреть diff, сохранить `SKILL.md` и промпты в репозитории.

Критерии проверки: мок регистрируется до триггерного действия; `npm run check`,
`npm run lint` и `npx playwright test` проходят. Для завершения задания создать
pull request без merge, проверить успешный GitHub Actions и поделиться ссылкой
на PR, запросив code review.
